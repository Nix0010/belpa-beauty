⚙️ Configuración de Conexión Cloud (Supabase)

Conecta tu base de datos y almacenamiento de Supabase para que los cambios en productos y fotos se guarden en la nube de forma segura.

📋 Pasos Rápidos para Configurar:
  1. Crea un proyecto gratis en supabase.com.
  2. En el SQL Editor, pega y ejecuta admin/supabase-schema.sql.
  3. Luego pega y ejecuta admin/seed-products.sql para cargar los 79 productos originales.
  4. Crea tu usuario administrador en Supabase Authentication.
  5. Pega aquí tu Project URL y tu Anon Key (de Project Settings > API).
